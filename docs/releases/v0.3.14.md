# v0.3.14

按浏览器批注调整 Web 的 Bot 模式侧栏。

- 恢复与普通聊天同样的底部栏，Bot 模式显示当前登录用户名与账号头像。
- 底部齿轮提供“进入设置”和“进入聊天模式”，账号按钮打开账号设置。
- 左上角恢复夭夭 Logo，搜索与加号保持原位置关系。
- 桌面 Bot 侧栏从 300px 加宽到 360px。
- 列表名称、消息预览和时间各缩小 2px，分别为 15px、13px、10px。

本次为 Web 更新，继续配套 iOS 1.3（175）。
