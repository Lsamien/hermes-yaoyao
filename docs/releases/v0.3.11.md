# v0.3.11

调整 Bot 模式侧栏与普通聊天的底部入口。

- Bot 模式去掉侧栏的“聊天列表”标题和普通聊天分组的“聊天”标签，保留置顶标识。
- Bot 模式桌面侧栏由 264px 加宽至 300px；折叠宽度和手机网页抽屉延续原样式。
- 普通聊天移除侧栏“聊天”功能入口，底部齿轮打开“进入设置”和“进入 Bot 模式”菜单。
- 保留原有账号区域行为与 Agent 切换，并支持菜单键盘操作和关闭设置后的焦点恢复。

本次仅更新 Web，继续配套 iOS 1.3（173）。
