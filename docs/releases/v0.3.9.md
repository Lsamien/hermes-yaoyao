# v0.3.9

按浏览器批注精简聊天模块侧栏，并统一头像容器的透明背景。

- 移除消息、侧栏、搜索结果及输入提示头像外层的黑色/灰色底板，保持头像本身和动态状态。
- 聊天模块侧栏只保留顶部 Logo 与操作、搜索、聊天列表和底部账号/设置栏。
- 展开时在折叠按钮右侧增加加号；折叠后加号位于 Logo 下方，菜单仅包含“新建 Bot”和“新建群聊”。
- 搜索使用弹出层，提供“未归档”和“已归档”分类；切换分类保留关键词，搜索结果使用对应聊天的真实头像。
- 支持折叠侧栏直接搜索、键盘关闭/焦点恢复和移动端抽屉。

本次为 Web 界面更新，继续配套 iOS 1.3（173）。iOS 头像组件及直接容器已检查，没有同类额外底板。

## 验证

- 85 个测试文件、490 项测试，以及类型检查、生产构建通过。
- 浏览器验证展开与折叠后的加号位置、两项创建菜单、搜索分类与焦点恢复、归档恢复、移动抽屉，以及浅色和深色主题下的透明头像容器。
