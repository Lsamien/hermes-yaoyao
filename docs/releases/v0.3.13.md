# v0.3.13

修复 Bot 聊天中的文本文件预览，并配套 iOS 1.3（175）的聊天滚动修复。

- Web 根据附件原始文件名和 MIME 类型选择文本预览器，修复“报告”等无扩展名链接无法预览正文的问题。
- iOS Bot 聊天接入普通聊天的文件预览器，支持文本与 Markdown，继续通过已认证的 Web 文件接口读取。
- iOS Bot 聊天增加原样式的“回到最新消息”按钮。
- 用户手动点击到底会停止当前滑动并执行跳转；自动跟随消息仍保留浏览历史时的延后策略。
- 同步到底后的按钮可见状态，避免已经到底仍残留按钮。

## 验证

- Web 浏览器通过实际附件链接打开文本正文。
- iOS 使用长会话验证文本预览、快速滑动后的到底动作与按钮可见性；普通聊天验证相同的手动跳转。
- Web 500 项测试、类型检查和生产构建通过；iOS 80 项单元测试与两项界面验收通过。
