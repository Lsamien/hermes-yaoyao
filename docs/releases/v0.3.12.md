# v0.3.12

原团队群聊升级为 Bot 模式，统一从设置进入，并记住当前设备上次使用的模式。

- Bot 模式继续使用 Web 保存的自建 Bot 与群聊，不混入基础 Agent 的原生会话。
- 移除旧团队导航入口；普通聊天与 Bot 模式在设置中互相切换，重新打开时恢复最后使用的模式。
- 列表按参考照片调整为顶部账号头像、搜索和加号；大头像、名称、最后消息和简洁时间排列在同一列表中，群头像由真实成员合成。
- 手机网页直接显示 Bot 列表，打开会话后可返回列表；搜索弹层保留未归档和已归档分类。
- 配套 iOS 1.3（174）同步设置入口、列表样式、模式记忆及搜索。

## 验证

- Web 86 个测试文件、500 项测试通过，类型检查与生产构建通过。
- 浏览器验证设置切换、两种模式恢复、手机列表、群聊及搜索。
- iOS 40 项单元测试通过；模拟器验证两种模式各自重启恢复、设置切换、搜索与打开旧聊天，签名构建为 1.3（174）。
