# v0.3.7

恢复迁移时漏接的新建团队模板入口。Web 使用原来的模板卡片，iOS 复用“选择预设团队”页面，聊天首页及团队入口保持原有布局。

- 恢复信息收集、产品设计、软件开发、文案书写、项目管理、数据分析、会议协作、运维保障 8 套预设，以及自定义团队。
- 模板带入名称、群规则、角色分工和管理员；成员从已创建的 Agent 中选择，角色可以重新分配，人数不足时提示补充 Agent。
- 角色分工保存在对应群聊中，不修改已有 Agent 的名称、头像和独立规则；执行时使用成员的最新名称，单聊不继承群内职责。
- 保留群成员增减与管理员保护，移除成员时同步清理其群内分工。

配套 iOS 1.3（172）。

## 验证

- 85 个文件、469 项 Web 测试通过，类型检查和生产构建通过。
- 浏览器验证 8 套模板、人数不足提示、角色重新分配、保存后的分工和聊天。
- iOS 12 项协议与模板测试及完整界面验收通过，模板选择、创建、分工保存使用原有导航层级。
