# v0.3.0 — Web 原生角色与固定成员聊天

团队、角色和聊天记录现在由 Web 服务直接保存和运行。基于已有 Hermes Profile 创建角色并设置提示词，角色单聊与群聊显示在同一列表；群成员创建后固定，不再提供独立话题列表。

文件归档、语音配置、上下文快照、节点管理与团队推送迁入 Web。移除 Yaoyao 插件及其安装、版本检查和升级流程。原生 Hermes 对话保留独立入口。

## 配套客户端

请同时更新至 iOS 1.3（164）。iOS 统一连接 Web 地址，角色会话按登录账号隔离；Hermes 暂时不可用时仍可登录 Web 查看已有聊天。

## 升级方式

这是不兼容旧接口的版本。首次切换请整体替换 Web 部署，不通过旧版插件升级流程更新。新体系从空数据库开始，旧团队、话题和插件配置不自动导入，旧文件原地保留。

Web 上游仍为标准 Hermes 9119 服务。无需安装 Yaoyao 插件；Kanban 仍是独立可选功能。

## 验证

发布前执行 Web 全量单元测试、类型检查、生产构建和新聊天浏览器端到端测试。iOS 使用当前提交执行设备归档、开发签名导出和包完整性检查。该 IPA 供签名配置中已注册的设备使用。
