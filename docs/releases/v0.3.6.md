# v0.3.6

群聊设置支持添加和移除成员，当前管理员不能移除。若需移除原管理员，先更换管理员并保存，再调整成员。

- Web 与 iOS 保留原有设置页面，放开成员选择；已建群可以只保留管理员，最多 8 位成员。
- 成员变化后同步更新群头像、人数和 @ 列表，保留聊天历史及原有会话。
- 移除成员时自动清理自动回复名单与尚未执行的回复队列；已经开始的回复可以完成，后续不再调度该成员。
- 服务端校验管理员保护、成员归属、重复成员及已归档角色，避免绕过界面限制。

配套 iOS 1.3（171）。

## 验证

- 85 个文件、468 项 Web 测试通过，涵盖管理员保护、成员增减、历史保留、自动回复清理、执行中移除及新成员回复。
- 浏览器完成成员移除与新增、管理员选项禁用、重新打开设置、跨页面同步、头像组合和新成员聊天验收。
- iOS 的 9 项协议测试及完整导航、群设置界面验收通过；成员变化保存后重新打开仍然有效。
