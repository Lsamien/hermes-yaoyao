# v0.3.8

将原团队协作调度迁入 Web，以持久化的成员任务和批次替换简化队列。

- 管理员模式下，用户消息先由管理员处理。管理员可以按依赖逐个委派，或一次委派多名成员并行执行；整批成功、失败或中断后只复核一次，复核不额外消耗轮数。
- 自由模式恢复自动参与接力；无关的自动成员可以静默退出，管理员必须公开处理。支持默认 3 轮、1～100 轮和不限轮数。
- 执行中继续接收消息并持久化排队。同一群成员串行、每群最多 3 个执行、全局最多 4 个执行；排队消息不会提前进入上一轮上下文。
- 支持整轮停止和单成员停止；停止未确认时继续核对，避免误报已停止。并行审批与澄清绑定各自成员任务，防止串线和重复提交。
- 保存批次与后续调度计划，重启后核对原执行，不重复提交提示词或重复复核。现有 v0.3.x 未完成任务向新任务记录转换。
- 上下文按触发点有界读取，保留首尾、思考摘要、工具名称、附件与失败摘要；隔离其他聊天及缺失历史记录。
- Web 与 iOS 继续使用原有聊天组件，成员头像独立显示运行/等待状态，设置中提供成员停止与不限轮数。

配套 iOS 1.3（173）。逐项迁移证据见 [协作迁移对照](../workspace-orchestration-parity.md)。
