# v0.3.10

修复 Web 历史对话中，用户从 iOS 发送的 Profile 图片被显示成文字的问题。

- 用户图片解析同时识别默认目录和 `.hermes/profiles/<profile>/images/`，保留原始 Profile 路径。
- 批量图片恢复为可预览附件，隐藏对应的图片说明、`@image:` 和截图占位标记；正文与原始文件名保留。
- 继续使用现有的鉴权图片读取接口；拒绝目录越界、编码分隔符、反斜杠及控制字符。
- 本次仅更新 Web，继续配套 iOS 1.3（173）。

## 验证

- 85 个测试文件、498 项测试通过，覆盖用户消息解析和媒体代理回归。
- 浏览器通过实际 Web 与上游接口加载九张用户图片，验证点开与切换预览；原有生成图片预览通过。
- 类型检查、生产构建通过。
